commands:
--------

1. git init:
    - initialize existing directory as git repo
    - automatically make .git folder in which general configration and which is hidden folder
2. git add README.md:
    - get tracked file from untracked file
    - get symbol 'U' means "untracked file" because we cannot add
    - after this command this symbol in 'A' means "added"
    - to remove: git rm --cached <file>
3. git commit -m "first commit"
    - commit your staged content as a new commit snapshot
4. git branch -M main 
    - rename your branch in "main" 
    - not compulsary
5. git branch
    - list your branches. 
    - a * will appear next to the currently active branch
6. git remote add origin https://github.com/RNandini-11/git_practice.git
    - give destination repo url
7. git remote -v
    - Show remote repository URLs
8. git push -u origin main
    - Upload commits to GitHub.
    - push code to origin from main
9. git status
    - Check file changes

Branching Strategies:
---------------------

- git branch -> Lists local branches

now make another branch names 'developer-a'
now here developer-a want to chnage or add some code.
then switch branch main to developer-a then change that code.

- git branch developer-a -> developer-a create story add add div() in python file in main branch	
    - Creates a new branch
    - exact replica of main branch
- git switch developer-a	-> Switches to a branch
- git branch --> see active branch now developer-a

change code in file
- git status with U symbol
- git add .
- git status with A symbol
- git commit -m "developer story" 

now complete work as a 'developer-a' and merge this branch with 'main'
- git switch main
    - then is remove that file because this div() i not write in 'main' branch because we write in 'developer-a'
    - so we merge two branch
- git merge developer-a
